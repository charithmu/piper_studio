# Human Checkpoint Log

One line per human-signed checkpoint from `ORCHESTRATION.md`. The supervisor
appends here after each sign-off (or fail). Keep entries terse; defects link
to the responsible agent.

Format:

```
YYYY-MM-DD | Checkpoint <id> | pass|fail | <reviewer> | <defects or "-">
```
