# Meshes

`realsense_mid_stand.dae`: AgileX's wrist camera stand for the Piper gripper, copied unmodified from
https://github.com/agilexrobotics/agx_arm_sim (`agx_arm_description/meshes/realsense_mid_stand.dae`, commit f8cd8b1,
2026-07-29). That repository declares the MIT licence (README, `package.xml`; copyright agilexrobotics).
Its mounting pose comes from the same repository's `urdf/piper_girpper_D435.urdf` (see `urdf/mounts/agilex_mid_stand.xacro`).

`realsense_mid_stand_collision.stl` and `d435_collision.stl`: low-poly collision shapes of the stand (its own mesh, vertices clustered on a 3 mm grid) and the D435
(convex hull of the clustered vertices), generated from the two visual meshes by `tools/build_collision_meshes.py` (largest gap to the visual 1.5 mm). The URDF uses them with the visual's origin; a custom stand mesh falls back to a box.

`d435_colored.dae` (its `up_axis` says Y_UP, but the vertex data is already in the frame its URDF origin expects: loaders must not rotate it again; the model viewer does not): the D435 with real part colours, generated by `tools/build_d435_mesh.py` from MuJoCo Menagerie's
`realsense_d435i` (Apache-2.0, Google DeepMind; parts and colours from its `d435i.xml`). Same frame and geometry as
`realsense2_description`'s grey `d435.dae`, so `urdf/cameras/d435.xacro` uses it in its place.
